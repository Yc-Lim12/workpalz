# WorkPalz

**A Dynamic Island for Windows that notices when new hires are struggling, early.**

Built for AI Future Makers Bootcamp 2026.

New employees often disengage in their first few months without anyone noticing
until it's too late. WorkPulse sits quietly at the top of the screen, learns each
person's own work rhythm, and gently steps in when something shifts — offering
help, not judgement.

### How it works
1. Tracks activity **categories** only (Development, Meetings, Entertainment, Away)
2. Builds a personal baseline from the first weeks
3. Detects meaningful changes with simple, explainable maths
4. Gemini turns those numbers into a supportive insight
5. The island expands, explains why, and suggests an action

### Privacy by design
- No screenshots, keystrokes, URLs or window titles stored
- Data stays on the device
- Managers only see an opt-in weekly signal, never app names
- Not used for performance reviews

### Tech stack
Electron · React · TypeScript · Tailwind CSS · Framer Motion · SQLite · Gemini API
