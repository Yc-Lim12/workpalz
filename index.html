How it works

The feedback loop

This is the Challenge 4 flow from the guide: employee feedback, AI finds themes, HR reviews, support action. WorkPalz adds the last step most tools skip.

  1. Employee speaks upCheck-in, a question the handbook can't answer, or an IT/HR request
  2. AI finds themesGroups feedback by team, counts people, compares with last week
  3. HR reviewsReads the quotes and the suggested action, then decides
  4. Action takenOne-click follow-up, tracked to done
  5. Employee hears backThe island expands to say what was fixed
For new hires

The island

Sits at the top of the screen and grows only when it has something to say. On a MacBook it wraps around the notch. Ctrl+Alt+Space opens it from any app.

For HR

The dashboard

Opens with Ctrl+Alt+H. Updates live as new hires use the island. Filter any view by team.

Responsible AI · ESG

Privacy and accessibility

Privacy by design

  • Only voluntary input. No app, screen, keystroke or camera tracking, and no mood guessing.
  • Check-ins and questions are anonymous to HR by default. Requests carry a name because IT needs it.
  • Names never go to the AI. It sees P1, P2 only to count people.
  • The HR window receives cleaned data. Hidden IDs are used only to send updates back.
  • Download and delete your own data from the island.
  • AI suggests, people decide. Never used in performance reviews.

WCAG 2.2 AA

  • Everything works by keyboard, with a visible focus ring and focus moved into each view.
  • Real labelled form controls, so screen readers announce options and choices.
  • Status changes are announced: new check-in, answers, analysis done.
  • Text contrast at least 4.5:1, borders and focus 3:1, checked by script.
  • Never colour alone: moods, severity and status always have words.
  • Honours reduce motion and Windows high-contrast mode. 44px targets.

For the pitch

Two-minute demo

On a Mac, use Cmd+Option instead of Ctrl+Alt.

  1. Press Ctrl+Alt+R to reset, then Ctrl+Alt+H to open the dashboard.
  2. On the island, Ask WorkPalz "What is a Q4 OKR?", then "how do I get staging server access" to show a handbook gap.
  3. Press Ctrl+Alt+C. The pill pulses. Answer Frustrated with "Still waiting on my software licence".
  4. On the dashboard, click Analyse this week: Engineering shows 4 of 5, up from 1 last week.
  5. Create follow-up, open Follow-ups, tick it done. The island expands with the update.

This build stores data on one computer with no sign-in. A company rollout needs a shared database, single sign-on, an HR admin page for the handbook, and a security and PDPA review.
